# ASTECNOR · Gestor PRL

Frida Rosa Vistoso Reddersen · Bootcamp Talento Digital.

Aplicación frontend para registrar charlas de prevención de riesgos en una empresa ficticia. Cada registro contiene tema, rubro, responsable y fecha.

Desarrollada con HTML, CSS y JavaScript. Utiliza localStorage para conservar registros en el navegador, valida los campos y presenta avisos ante errores de almacenamiento.

Esta versión no incluye autenticación ni sincronización entre equipos. Las referencias normativas son informativas.
