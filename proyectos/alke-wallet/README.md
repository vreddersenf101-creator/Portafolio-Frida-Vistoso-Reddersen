# Alke Wallet · Trinky Wallet

Frida Rosa Vistoso Reddersen · Bootcamp Talento Digital.

Billetera educativa con ingreso de demostración, depósitos, agenda de contactos, envíos e historial. Desarrollada con HTML, CSS, JavaScript, jQuery y Bootstrap.

Valida montos enteros positivos y fondos disponibles. El saldo, los movimientos y los contactos se conservan en el navegador. No procesa dinero real ni incluye autenticación de servidor.

Las bibliotecas incluidas conservan sus licencias originales.
