## Presentación

Portafolio de proyectos educativos que presenta habilidades, decisiones técnicas y aprendizajes en desarrollo web. Incluye perfil profesional, proyectos, caso de estudio y contacto.

## Proyectos

- **Alke Wallet · Trinky Wallet:** simulación de billetera digital con depósitos, envíos, contactos e historial. Conserva datos en el navegador y no procesa dinero real.
- **ASTECNOR:** prototipo frontend para registrar y consultar charlas de prevención de riesgos. Incluye validación de formularios y persistencia local.
- **Servidor de registro de actividades · Módulo 6:** aplicación independiente para consultar el estado del servidor y registrar accesos en archivos.

## Tecnologías
