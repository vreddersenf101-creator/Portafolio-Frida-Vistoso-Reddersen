# Servidor de registro de actividades

Frida Rosa Vistoso Reddersen · Módulo 6 · Talento Digital.

Aplicación educativa con Node.js y Express. Presenta el estado del servidor, permite actualizar la consulta y conserva un registro de accesos en archivos.

Organiza sus responsabilidades en rutas, controladores, middleware y servicio de persistencia. Incluye pruebas del registro, las respuestas del servidor y el manejo de errores.

No requiere una base de datos ni depende de ASTECNOR.
